# 两层分类模型端到端优化

在保持每个样本两类 logits 等价的前提下，优化整个模型的一次批推理。输入为任意大小的二维批次，每个样本有两个有限浮点特征。模型由两层固定权重的仿射变换组成。可以逐层计算，也可以折叠静态权重后执行一次仿射变换。

[baseline.py](baseline.py) 同时承担起始实现、正确性参考和官方性能基线三个角色。[参考答案](answer/solution.py) 演示了两层折叠。选手只提交自己的 `solution.py`，其中 `predict(batch)` 须保留输出形状、内容和样本顺序。

精度门槛、计时边界和可改范围见 [契约](contract.yaml)。完整通过精度检查，再比较相同输入下的端到端耗时，见 [共享评分规则](../../scoring/latency-ratio.v1.yaml)。
